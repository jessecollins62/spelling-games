# Lindamood-Bell Word List Reference

## Source

**Seeing Stars: Star Words 1–1000**
Author: Nanci Bell  
Publisher: Gander Publishing  
Scribd document: https://www.scribd.com/document/526482246/star-words-1-100

Local images saved in: `LMB-words-image/` (10 JPG files, pages 1–10). These are copyrighted book pages, so they are kept on this computer only and are not in the git repo (see `.gitignore`).

## Structure

Each page covers 100 words organized into 4 Sets of 25 words each:

| Image file (page) | Star Words | Game lists |
|---|---|---|
| 1-*.jpg | 1–100   | LMB 1–10   |
| 2-*.jpg | 101–200 | LMB 11–20  |
| 3-*.jpg | 201–300 | LMB 21–30  |
| 4-*.jpg | 301–400 | LMB 31–40  |
| 5-*.jpg | 401–500 | LMB 41–50  |
| 6-*.jpg | 501–600 | LMB 51–60  |
| 7-*.jpg | 601–700 | LMB 61–70  |
| 8-*.jpg | 701–800 | LMB 71–80  |
| 9-*.jpg | 801–900 | LMB 81–90  |
| 10-*.jpg | 901–1000 | LMB 91–100 |

Each page's 100 words are split sequentially into 10 game lists of 10 words each (e.g., page 4 words 1–10 → LMB 31, words 11–20 → LMB 32, etc.).

## Notes

- Words are taken in the order they appear in the original Sets (reading left column top to bottom, then next column).
- Decoys for the Curtain game are auto-generated by the `fd()` helper in `words.js`.
- The Blaster game will not be available for LMB lists (no meanings/lookalikes defined).
- To add more word groups (e.g., a second Seeing Stars book), follow the same naming convention: next series would start at LMB 101.
